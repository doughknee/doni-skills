# Marketing / Landing

**Slug:** `marketing`
**What it is:** Public pages that sell: homepage, landing pages, pricing, feature tours, about. The user is deciding, not working.
**Default aesthetic (brief is silent):** `gradient-mesh`

## Allowed aesthetics
- everything except the two banned below; this is the widest context

## Banned aesthetics
- brutalism (unless the brand is itself anti-design)
- terminal (unless the product is a CLI)

## Must-have sections
- Nav with one CTA
- Hero: headline, subhead, CTA pair, hero visual
- Social proof: logo bar or stat row
- Feature sections (3 to 5), alternating layout
- Testimonials
- Pricing (if applicable)
- FAQ
- Final CTA band
- Footer with sitemap

## Layout skeleton
- Max-width 1200px (or the recipe's `--max-w`), 24px gutter
- Section rhythm from the recipe's `--section-y`
- Hero visual: product screenshot (SaaS), photograph (physical), illustration (consumer), or type-only (agency)
- Alternate left-image/right-text per feature section

## Component list
- Nav
- Hero
- Logo bar
- Feature card
- Testimonial card
- Pricing card with featured tier
- FAQ accordion
- CTA band
- Footer

## Notes
- Pick the aesthetic by the product's audience: technical → dark-saas, mono-editorial, gradient-mesh; consumer → playful, scandinavian, photo-led, organic; creative → neo-brutalism, collage, editorial, motion-first
- If the brief names a competitor, match the competitor's family then pick the adjacent aesthetic, not the same one
