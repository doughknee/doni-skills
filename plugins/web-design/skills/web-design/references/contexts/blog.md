# Blog / Publication

**Slug:** `blog`
**What it is:** Reading first. Article pages, an index, author pages, maybe a newsletter signup.
**Default aesthetic (brief is silent):** `editorial`

## Allowed aesthetics
- editorial
- minimalism
- japanese-minimal
- scandinavian
- mono-editorial
- swiss
- hand-drawn
- luxury (fashion and culture only)
- dark-saas (only if the user asks)
- terminal (dev blogs, only if the user asks)

## Banned aesthetics
- everything else; reading contexts stay light and quiet

## Must-have sections
- Masthead with site name and 3 to 5 nav links
- Index: featured post plus list or grid
- Article: title, byline, date, reading time, body, footer with related posts
- Author page
- Newsletter signup
- Footer

## Layout skeleton
- Article body max-width 680px (65 to 75 characters per line)
- Body type 18 to 20px, line-height 1.6 to 1.7
- Index max-width 1080px
- Images full-bleed or body-width, never floated
- Headings use the recipe's display face; body may use a serif even when the recipe is sans

## Component list
- Masthead
- Post card (image, title, excerpt, meta)
- Article header
- Pull quote
- Code block
- Footnote
- Newsletter form
- Pagination

## Notes
- Override the recipe's `--max-w` with 680px for article bodies
- If the recipe has no serif, add one for body: Source Serif 4, Newsreader, or Literata
