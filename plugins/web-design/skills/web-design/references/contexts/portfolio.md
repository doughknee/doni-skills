# Portfolio

**Slug:** `portfolio`
**What it is:** A person or small studio showing work: grid of projects, case study pages, about, contact.
**Default aesthetic (brief is silent):** `swiss`

## Allowed aesthetics
- swiss
- editorial
- luxury
- motion-first
- neo-brutalism
- collage
- photo-led
- minimalism
- japanese-minimal
- grunge (music, tattoo, wrestling)
- hand-drawn (illustrators)
- pixel (game devs)

## Banned aesthetics
- enterprise
- material
- alegria
- flat

## Must-have sections
- Nav: name and 2 to 3 links
- Intro statement (one or two lines)
- Work grid or list
- Case study: hero, problem, process, outcome, next project
- About with photo
- Contact

## Layout skeleton
- Work grid 2-up or 3-up with generous gaps (32px+)
- Case study body max-width 760px, images full-bleed
- Let the work carry the page: chrome is minimal in every allowed aesthetic

## Component list
- Project card (image, title, one-line role)
- Case study header
- Image with caption
- Before/after
- Contact form or mailto

## Notes
- Density follows subject (router rule 5): if the work is visual, pick the quieter candidate
- If the person is a developer, `mono-editorial` or `dark-saas` are allowed despite not being listed
